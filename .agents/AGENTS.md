# Vividpersona Project Rules & Reference API Endpoints

## FAL.AI Image Model API Reference Endpoints

Below are the key image model APIs at fal.ai that are used for reference/inspiration in this project:

- **seedream 4.5 text2img**: `https://fal.ai/models/fal-ai/bytedance/seedream/v4.5/text-to-image/api`
- **seedream 4.5 image edit**: `https://fal.ai/models/fal-ai/bytedance/seedream/v4.5/edit/api`
- **gpt 1.5 txt2img**: `https://fal.ai/models/fal-ai/gpt-image-1.5/api`
- **gpt 1.5 edit**: `https://fal.ai/models/fal-ai/gpt-image-1.5/edit/api`
- **gpt 2 txt2img**: `https://fal.ai/models/openai/gpt-image-2/api`
- **gpt 2 edit**: `https://fal.ai/models/openai/gpt-image-2/edit/api`
- **ideogram 4 txt2img**: `https://fal.ai/models/ideogram/v4/api`
- **ideogram 4 img2img**: `https://fal.ai/models/ideogram/v4/image-to-image/api`
